## 📋 О проекте

**UniPulse AI** — аналитическая система оптимизации поступления, формирующая персонализированные образовательные траектории.

Система анализирует академические показатели школьника/студента (баллы ЕНТ, результаты IELTS/SAT, средний балл GPA), финансовые возможности и карьерные интересы, после чего формирует персональный список ВУЗов по трём уровням риска:

- 🟢 **Safety (Безопасная зона):** Высокая вероятность прохождения на грант или бюджет.
- 🟡 **Target (Целевая зона):** Реалистичные шансы при выполнении стандартных требований.
- 🔴 **Reach (Зона риска / Мечта):** Высокая конкуренция, требующая максимальной подготовки.

Проект ориентирован как на казахстанские университеты (**Назарбаев Университет, ЕНУ, KBTU, AITU, КазНУ и др.**), так и на международные ВУЗы (**KAIST, NUS, TUM, Polimi, Charles University, Bilkent и др.**).

## ✨ Ключевые возможности

- 🎛️ **Интерактивный симулятор «What-If»:**  
  Плавное регулирование показателей (ЕНТ, IELTS, SAT, GPA, Бюджет) с мгновенным перерасчетом шансов и перераспределением ВУЗов по категориям.
- 🏫 **Детализированные карточки ВУЗов:**  
  Информация о проходных баллах, обязательных предметах, минимальном GPA/IELTS, дедлайнах подачи документов и стипендиальных программах.
- 💰 **Финансовый калькулятор расходов:**  
  Расчёт полной стоимости года обучения и проживания (аренда, транспорт, личные расходы, скидки и государственные гранты).
- 📝 **Система персональных заметок:**  
  Возможность сохранять личные комментарии, контакты приёмных комиссий и заметки по каждому университету прямо в интерфейсе.
- 🌓 **Адаптивный интерфейс и Тёмная тема:**  
  Полностью отзывчивый дизайн с поддержкой Dark Mode и мобильной плавающей панелью управления.

## 🛠️ Технологический стек

- **Frontend:** HTML5, Vanilla JavaScript (ES6+)

## 🚀 Быстрый старт

Так как текущая версия представляет собой клиентское SPA-приложение, запуск не требует сложной настройки окружения.

### Предварительные требования
- Любой современный веб-браузер (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge).
- (Опционально) Расширение **Live Server** для VS Code или утилита `serve`.

### Локальный запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://github.com/Arlans-/unipulse-ai.git](https://github.com/Arlans-/unipulse-ai.git)
   cd unipulse-ai

```

2. **Запустите проект:**
* Откройте файл `index.html` (или `unipulse_ai2_2.html`) напрямую в браузере.
* Или запустите через локальный HTTP-сервер:
```bash
npx serve .

```




3. **Откройте в браузере:**
```text
http://localhost:3000

```
